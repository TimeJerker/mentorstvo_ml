# Insurance Data Analysis (Manual Implementation)

Этот проект — практическая работа по закреплению основ Python, ООП и математической статистики в рамках курса по Machine Learning. 

### Основной функционал:
1. **Загрузка и очистка данных:** 
   - Ручной парсинг CSV-файла через модуль `csv`.
   - Валидация типов данных (преобразование строк в `int` и `float`).
   - Очистка датасета от строк с пустыми значениями.
2. **Математическая статистика (реализовано вручную):**
   - Расчет **Математического ожидания** (среднего арифметического).
   - Расчет **Дисперсии** (меры разброса данных).
   - Расчет **Условной вероятности** (например, вероятность того, что человек курит, при условии высокого чека страховки).
3. **Объектно-ориентированный подход:** 
   - Вся логика инкапсулирована в классе `lab1`.
4. **Экспорт результатов:** 
   - Итоговые метрики сохраняются в файл `report.json`.
